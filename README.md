## Estructura del Proyecto
- `index.html`: Página de inicio.
- `catalogo.html`: Listado de servicios en cuadrícula (CSS Grid).
- `contacto.html`: Formulario de agendamiento con validación JS.
- `css/style.css`: Estilos compartidos para todo el sitio.
- `js/funciones.js`: Lógica de validación del formulario.
- `img/`: Carpeta preparada para las imágenes del proyecto.

## Cómo ejecutarlo
Simplemente abre el archivo `index.html` en cualquier navegador web. Las rutas están configuradas de forma relativa, por lo que la navegación funcionará inmediatamente.
